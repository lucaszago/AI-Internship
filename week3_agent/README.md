# Week 3 — Ops revenue analyst agent

Session 3 (Path A) agent for the [TAI Labs Week 3 assignment](https://tailabs.ai/ai-eng-syllabus/week-3/week-3-agent-assignment-guide).

**Stack:** Google ADK (Gemini)  
**Job:** When a manager asks about sales performance, the agent runs **read-only SQL** on a small orders database and returns a short **KPI brief** (numbers → insight → optional next action).

This folder is **Week 3 only**. Week 1/2 FastAPI + Pinecone RAG stay at the **repo root** (`main.py`, `rag/`, `ui/streamlit_app.py`, Render). See the [root README](../README.md) for RAG deploy docs.

---

## Why this is an agent (Maven one-liner)

> This is an **agent** because it chooses and revises SQL based on tool results, not a hardcoded query script. It is not a fixed A→B→C workflow.

| Module | Role |

| `session_runner.py` | Async ADK `Runner`; labels Think / Act / Observe |

| `ui/agent_app.py` | Streamlit: question → steps → KPI brief |
| `agent_api/` | FastAPI `POST /agent` + `GET /agent/health` (wired in root `main.py`) |

## Prerequisites

1. Python 3.12+ and [uv](https://github.com/astral-sh/uv) (or sync deps via `uv sync` from repo root)
2. `GOOGLE_API_KEY` from [Google AI Studio](https://aistudio.google.com/)
3. Copy env template:

```bash
cp week3_agent/.env.example week3_agent/.env
# edit: GOOGLE_API_KEY=your_key_here
```

| Variable | Example | Purpose |
| --- | --- | --- |
| `GOOGLE_API_KEY` | `...` | ADK / Gemini |
| `DB_PATH` | `./data/demo.db` | SQLite file (relative to `week3_agent/`) |
| `AGENT_MAX_STEPS` | `8` | Bound LLM calls / agent loop (`RunConfig.max_llm_calls`) |
| `AGENT_MODEL` | `gemini-3.6-flash` | Gemini model id |
| `AGENT_MAX_ROWS` | `50` | Cap rows returned by `run_sql` |

Never commit `.env`.

## Database (engineer way)

- **Schema** lives in `sql/001_schema.sql` (versioned).
- **Seed** runs via `agent/seed_demo_db.py` (reproducible).
- Agent opens the DB **read-only**; only the seed script writes.

Tables:

- `customers` — name, city
- `products` — category, price
- `orders` — amount, status (`completed` / `cancelled` / `pending`), dates

```bash
# Always run from the AI-Internship repo root (parent of week3_agent/):
cd /path/to/AI-Internship

uv run python week3_agent/agent/seed_demo_db.py

sqlite3 week3_agent/data/demo.db ".schema"
```

If your shell is already inside `week3_agent/`, use the shorter path instead:

```bash
uv run python agent/seed_demo_db.py
```

Do **not** run `python week3_agent/agent/...` from inside `week3_agent/` — that looks for a nested `week3_agent/week3_agent/...` and fails.

## Real tool

**`run_sql(sql: str) -> dict`**

- Executes against `DB_PATH`
- **SELECT only** (reject INSERT/UPDATE/DELETE/DROP and stacked statements)
- Opens SQLite with `mode=ro`
- Truncates large results (`AGENT_MAX_ROWS`)
- Returns errors as observations (does not crash the loop)

Smoke test (no API key needed):

```bash
uv run python week3_agent/agent/tools.py
```

Hardcoded fake numbers without a DB do **not** count for Path A.

## How to run

### 1. Seed DB

```bash
# from AI-Internship repo root:
uv run python week3_agent/agent/seed_demo_db.py
```

### 2. Agent smoke (no Gemini call)

```bash
uv run python week3_agent/agent/agent.py
```

### 3. CLI proof (Think → Act → Observe)

Requires `GOOGLE_API_KEY` in `week3_agent/.env`.

```bash
# default question (city with highest completed revenue):
uv run python week3_agent/agent/run_cli.py

# custom question:
uv run python week3_agent/agent/run_cli.py "What percent of orders are cancelled?"
```

You should see labeled steps like:

```text
1. [Think] Model chose tool `run_sql`
2. [Act] run_sql(SELECT ...)
3. [Observe] run_sql → columns=... row_count=...
...
=== Final answer ===
...
```

### 4. Streamlit UI (Maven screenshot)

```bash
uv run streamlit run week3_agent/ui/agent_app.py
```

Open http://localhost:8501 — enter a manager question → **Run agent** → step log + final KPI brief.

Show for Maven: question → Think/Act/Observe (SQL + rows) → final brief. Do not show secrets.

---

### 5. FastAPI ``POST /agent`` (same process as RAG)

From repo root (keeps Session 1/2 ``/ask`` working):

```bash
uv run uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

```bash
curl -s http://127.0.0.1:8000/agent/health | python3 -m json.tool

curl -s -X POST http://127.0.0.1:8000/agent \
  -H "Content-Type: application/json" \
  -d '{"question":"Which city has the highest completed-order revenue?"}' \
  | python3 -m json.tool
```

Response includes ``answer`` plus ``steps[]`` (Think / Act / Observe). Implementation: ``week3_agent/agent_api/``.

## Dockerize

Repo-root [`Dockerfile`](../Dockerfile) runs the **same** FastAPI app (`/ask` + `/agent`) and seeds `demo.db` at image build time.

### Build & run locally

```bash
# from AI-Internship repo root
docker build -t ai-internship-api .

docker run --rm -p 8000:8000 \
  -e OPENAI_API_KEY \
  -e PINECONE_API_KEY \
  -e PINECONE_INDEX_NAME=document-chunks \
  -e GOOGLE_API_KEY \
  -e AGENT_MODEL=gemini-3.6-flash \
  ai-internship-api
```

Smoke:

```bash
curl -s http://127.0.0.1:8000/health | python3 -m json.tool
curl -s http://127.0.0.1:8000/agent/health | python3 -m json.tool
curl -s -X POST http://127.0.0.1:8000/agent \
  -H "Content-Type: application/json" \
  -d '{"question":"Which city has the highest completed-order revenue?"}'
```

Do **not** bake secrets into the image (`.dockerignore` excludes `.env`).
